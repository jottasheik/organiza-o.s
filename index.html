Configuração de Desenvolvedor (.env)

Zero configuração para seus clientes: eles só clicam em "Entrar com o Google"

Como funciona a Abordagem 2:

Você cadastra o Client ID e Secret do Google Cloud uma única vez no arquivo .env do seu servidor. Depois disso, qualquer cliente que acessar o sistema verá apenas o botão "Entrar com o Google". Ao clicar, a planilha é criada no Drive dele e o Google Agenda é conectado de forma totalmente invisível e automática!

Passos de Configuração Única (Lado do Desenvolvedor):

  1. No Google Cloud Console, ative as APIs: Google Calendar API e Google Sheets API.
  2. Em Tela de consentimento OAuth, configure como Externo e adicione os escopos de agenda e drive/planilhas.
  3. Em Credenciais, crie um ID do cliente OAuth (Aplicativo da Web) com o URI de redirecionamento: http://localhost:3000/api/auth/google/callback.
  4. Copie o Client ID e Client Secret gerados e cole no arquivo .env na pasta do sistema.
